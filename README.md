# Projetos Power BI: Evolução e Análises

**Esta é uma breve introdução dos meus estudos, que reflete meu aprendizado contínuo e minha busca por aperfeiçoamento na área de análise de dados utilizando o Power BI.**

## Descrição
Este repositório contém uma coleção de projetos desenvolvidos no Power BI, demonstrando minha evolução nas habilidades de criação de relatórios e dashboards. Cada etapa do projeto está documentada com capturas de tela mostrando a progressão das minhas habilidades, desde os primeiros dashboards até as análises mais avançadas.


Os dados utilizados estão organizados dentro de pastas específicas dentro do repositório. Cada pasta contém os arquivos de dados necessários para reproduzir os dashboards e relatórios.

## Evolução no Power BI

A seguir, você pode visualizar a evolução dos meus dashboards e análises. Cada imagem mostra um estágio diferente de desenvolvimento, com a implementação de novas funcionalidades e complexidade.

### 1. **Primeiro Dashboard: Análise Básica de Vendas**
No início do meu aprendizado no Power BI, criei um dashboard simples para análise de vendas, utilizando gráficos básicos como colunas, pizza, linha e etc.

![image](https://user-images.githubusercontent.com/65089744/204103455-2b2bb8d5-2a70-4500-932b-4c3eeea28793.png)

**Objetivo:** Mostrar o faturamento de vendas por produto e região.

### 2. **Segunda Etapa: Análise de Vendas Avançado**
Nesta fase, comecei a implementar seguimentação de dados, utilizando gráficos de pizza, barras, segmentação por tempo, região e categoria. Também adicionei comparações de vendas entre diferentes períodos, região e categorias.

![image](https://github.com/user-attachments/assets/b78012d1-29c8-44e2-8442-36b0c42e4076)

**Objetivo:** Comparar as vendas ao longo de diferentes períodos e identificar tendências de crescimento ou queda.

### 3. **Dashboard Avançado: KPI Area Comercial**
Com o tempo, passei a usar funcionalidades mais avançadas, como **medidas DAX** e **filtros dinâmicos**, para permitir uma análise mais profunda e interativa dos dados.
Nesse caso em especifico utilizei também um menu interativo,e outras funcionalidades especiais.

![image](https://github.com/user-attachments/assets/1570c266-acdf-481c-ad52-d5b8e4b4ab22)

**Objetivo:** Analisar dados multidimensionais, incluindo categorias de produtos, desempenho de vendas por região e segmentação de clientes.

### 4. **Balanço Patrimonial com Matriz**
Na quarta etapa, trabalhei com dados hierárquicos para criar um balanço patrimonial com a visualização em **matriz**, proporcionando uma análise contábil mais detalhada.
![image](https://github.com/user-attachments/assets/18b47491-e45d-468b-9a54-6b6f1a6ee11a)

Cada pasta contém os dados necessários para reproduzir os dashboards e as análises apresentadas nas imagens.

## Como Usar

1. **Baixe o repositório** ou faça o clone do repositório para o seu computador.
2. Abra o arquivo **.pbix** no Power BI Desktop para visualizar e interagir com os relatórios.
3. Os dados estão organizados nas pastas mencionadas acima. Para iniciar o projeto, basta carregar os dados apropriados no Power BI e seguir os mesmos passos para criar os dashboards.
